Overview

A design studio that teaches middle school students UX, built for Tech Access Foundation classrooms. I defined the product, drafted the ten-week curriculum, and directed the build.

Role

Product Lead

Audience

Middle school students

Built with

Figma, React 19, Vite, Tailwind CSS, plain JavaScript, localStorage, Git, Netlify

Status

Private preview

The problem

There was no kid-friendly tool that taught UX.

How can we teach middle school students UX in a tool that is easy to use, explains itself, and doesn't rely on AI?

Figma, Canva, and Wix teach visual craft. None of them give students a user, a goal, or a task, so a page can look great and still be impossible to use.

The key idea

Every project starts with a person

Kids design for themselves, so more rules don't stick. Instead, each project starts with a brief about a fictional person with a specific need, and students design for them.

The app checks what it can measure, like size and contrast. For everything else, it asks the student to decide.

The classroom

Built for how sessions actually run

01

Forty-minute lessons

Hour-long sessions leave about forty minutes of real work, so every weekly plan fits that and marks what to drop.

02

Guest volunteers

I bring in people from my network in different tech roles, so students see the range of work behind a product.

03

Build first, explain later

Students make a page in week one. Each lesson after that fixes a problem they've already hit.

04

Shared Chromebooks, no logins

No accounts. Students save their work by exporting a project.

Privacy

Student work stays on the device

Nothing leaves the browser. That keeps the app out of COPPA's consent and legal requirements and lets it run free as a static site. The tradeoff is no syncing between devices, which I accepted until a pilot proves accounts are worth it.

Walkthrough

Four studios and a course

01

The Course

Ten weekly lessons as an in-app slideshow, each ending with a task to try in the studio.

02

Web Design Studio

A drag-and-drop page builder on a 12-column grid, with design tips in the Inspector as students work.

03

Component Lab

Workspaces for buttons, badges, pop-ups, cards, and form fields, with a warning when colors are hard to read.

04

Bug Blocks

Scratch-style block coding. Students build a script, press Run, and watch the bug follow it.

Under the hood

Before adding features, I had the 4,842-line prototype split into 31 modules and moved into a Vite project under version control.

Where it stands

Private preview, curriculum in review

Tech Access Foundation's curriculum specialist is reviewing the draft. Two known issues:

  • No touchscreen drag-and-drop yet, so it runs on laptops and Chromebooks, not tablets.
  • Phones are cramped. The app works, but the canvas gets cut off.

Next steps
